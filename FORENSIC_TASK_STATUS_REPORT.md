## 4. New risks found during this verification

| ID   | Risk                                                | Detail                                                                                                                                                                                                                                                   | Suggested action                                                                        |
| ---- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| N-01 | **Re-running `SettingsSeeder` wipes CMS settings**  | It uses `updateOrCreate` for every key (`SettingsSeeder.php:53`), so a second run overwrites contact details, titles, login mode, etc. with defaults. The Hostinger runbook runs it once, which is fine — but it must never be run again on a live site. | Change to "create only if missing", or add a warning to the runbook                     |
| N-02 | **Temporary Hostinger domain may get indexed**      | Until a real domain is bought, the site lives on Hostinger's temporary domain; sitemap and canonical URLs will point there (`APP_URL`). If Google indexes it, the move to the real domain creates duplicates.                                            | Keep the temporary domain `noindex` (or don't publish it) until the real domain is live |
| N-03 | **Raw HTML `<title>` is always "DAS" without SSR**  | `app.blade.php:16`. Per-page titles appear only after JavaScript runs on Hostinger.                                                                                                                                                                      | Accept, or move to a VPS with SSR                                                       |
| N-04 | **Fallback e-mail differs from the CMS e-mail**     | `contact.ts` fallback `afazad@gmail.com` vs setting `afazad1@gmail.com`. If the setting is ever blank, enquiries are pointed at a different inbox.                                                                                                       | Remove the fallback (BE-07)                                                             |
| N-05 | **A failed deploy leaves the site on the 503 page** | Intentional (prevents new code running against an old database), but someone must re-run the workflow or `php artisan up`.                                                                                                                               | Add yourself as a required reviewer / watch failed-run e-mails                          |
